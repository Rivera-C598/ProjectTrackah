Arduino IoT Final Project

Design and simulate an Arduino-based Mini Smart System using Tinkercad Circuits.

Overview Requirements Groups Bonus Deliverables Documentation
01
Overview

Each group will design and simulate an Arduino-based Mini Smart System using Tinkercad Circuits. Your project must demonstrate the integration of sensors, components, and Arduino decision-making logic into one functional system that represents a real-world application.

Stack
Arduino UNO
C/C++ via Tinkercad
Tool
Tinkercad Circuits
Free, browser-based
Grouping
9 Groups
Up to 5 members each

Deliverables
Submit all of the following
  1. Tinkercad share link (circuit must be shared publicly)
  2. Screenshot of completed circuit
  3. Screenshot of simulation running
  4. Arduino code file (.ino)
  5. Completed documentation file (.docx)
Tinkercad Naming Format

Name your Tinkercad circuit exactly as follows:

Group [Number] - Final Project - [Project Title]

Example:

Group 3 - Final Project - Smart Storage Monitoring System
